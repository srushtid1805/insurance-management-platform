# Insurance Management Platform

A full-stack Insurance Management System built using React, Node.js, Express, and PostgreSQL.

## Features

- JWT Authentication
- Role-Based Access (Admin, Agent, Customer)
- Customer Management
- Policy Management
- Policy Assignment
- Payment Management
- Claims Management
- Document Upload & Verification
- Dashboards for Admin, Agent & Customer
- Search, Filter & Pagination

## Tech Stack

Frontend:
- React
- Bootstrap
- Axios
- React Router
- React Toastify

Backend:
- Node.js
- Express.js
- JWT
- Multer

Database:
- PostgreSQL

## Installation

### Backend

npm install
npm start

### Frontend

npm install
npm run dev

## Environment Variables

Backend (.env)

PORT=5000
DATABASE_URL=...
JWT_SECRET=...

Frontend (.env)

VITE_API_BASE_URL=http://localhost:5000/api
